## Project Overview

**CollabHub** is a team collaboration platform built as a Laravel 12 + Vue 3 SPA. It includes real-time chat, video calls, project/task management (Kanban/Scrum boards, sprints), document editing, calendar/CalDAV, invoicing, and role-based permissions.

## Commands

### Frontend
```bash
npm run dev          # Vite dev server
npm run build        # Production build
npm run openapi      # Generate TS types from OpenAPI spec
```

### Backend
```bash
php artisan serve    # Local dev server
php artisan migrate  # Run migrations
php artisan tinker   # Interactive REPL
```

### Testing
```bash
./vendor/bin/phpunit                        # All tests
./vendor/bin/phpunit --testsuite=Unit       # Unit tests only
./vendor/bin/phpunit --testsuite=Feature    # Feature tests only
./vendor/bin/phpunit --filter=TestName      # Single test
```

### Code Style
```bash
./vendor/bin/pint    # PHP formatting (PSR-2 via Laravel Pint)
```

### Docker (Laravel Sail)
```bash
docker-compose up -d   # Start dev environment (MySQL 8, Redis)
docker-compose down
```

## Architecture

### Backend (`app/`)
- **REST API** under `/api/v1/`, authenticated via Laravel Sanctum Bearer tokens (500 req/min)
- **Service layer** (`app/Service/`) holds business logic; controllers are thin
- **Policy-based authorization** (`app/Policies/`) for all resource access
- **Event-driven real-time** via Laravel Broadcasting → Pusher/Soketi WebSockets
- **API Resources** (`app/Http/Resources/`) format all JSON responses
- **Form Requests** (`app/Http/Requests/`) handle validation
- API docs auto-generated by Dedoc Scramble at `/docs/api.json`

### Frontend (`resources/js/`)
- Single entry point: `app.js` → Vue 3 SPA
- **Pinia** stores in `store/` for global state
- **Vue Router** in `router/` with route-level middleware (`router/middleware/`)
- **Axios** instance configured in `axios.js` (Bearer token from localStorage, CSRF)
- **Echo/Pusher** initialized in `bootstrap.js` for real-time listeners
- 226+ Vue components in `components/` using CamelCase naming
- TypeScript types in `types/` (models, services, core)
- TipTap 2 rich-text editor with ProseMirror for document collaboration; editor utility functions in `functions/editor/`

### Key Integrations
- **LiveKit** — video calls (`/api/v1/video-call/{chat}/start`)
- **Spatie Media Library** — file/image management with S3 support
- **CalDAV** — calendar sync via web routes
- **jsPDF + DOMPdf** — PDF export
- **PWA** — Vite PWA plugin, service worker, 5 MB cache

### Real-Time Channels
Broadcasting auth: `/api/v1/pusher/auth`
- Private channels for per-user notifications and chats
- Presence channels for online status

### Database Patterns
- Nested Set (Kalnoy) for hierarchical task relations
- Polymorphic relationships for media and notifications
- Soft deletes on most models

## Conventions

| Layer | Convention |
|---|---|
| PHP Models | `CamelCase` singular (`Task`, `ChatMessage`) |
| Controllers / Services / Policies | `CamelCase` + suffix (`TaskController`, `FileService`) |
| Migrations | `snake_case` with timestamp |
| Vue Components | `CamelCase.vue` |
| Pinia stores | `camelCase.js` |
| JS variables | `camelCase` |

## Theme
- Dark/Light mode toggled via localStorage; Tailwind `darkMode: 'class'`
- Brand colors: orange `#FFA500`, blue `#4A90E2` (defined in `tailwind.config.js`)
